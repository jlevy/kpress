# KPress 0.3.11

A faster sanitizer for hosts that never show what it removed.

## Sanitizer

- `sanitize_raw_html` takes `diagnose=False`. It returns the same sanitized HTML with no
  diagnostics, and skips the audit and the content comparison that write them.
  Neither feeds the output, which still comes from nh3 and the checkbox rewrite.
- The skipped work is most of the call.
  On an 85 KB document’s rendered HTML, the call took 25.7 ms with diagnostics and 3.3
  ms without, best of nine.
- A host that renders only to compare or measure the result passes it, as Metabrowser’s
  rendered Markdown diff does.
  The default is unchanged, so every render path still reports what it removed.
- Every sanitizer call in `tests/test_sanitize.py` runs a second time with
  `diagnose=False`, and that call must return the same HTML or raise the same error.

## Tests

- A pytest run that passes deletes its temporary output.

Runtime dependencies are unchanged.
