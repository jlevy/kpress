# KPress 0.3.8

Every code run in the shipped mono face, and a table-of-contents fix for headings that
are hidden.

## Code

- `<kbd>` and `<samp>` draw in the shipped mono face at the code size.
  They used the browser’s own monospace, beside code set in Planetaire Mono.
  `<var>` keeps the browser’s italic.
- Code, `<kbd>`, and `<samp>` inside a link’s preview popover draw in the shipped mono
  face too. The popover sits outside the document wrapper, so the document’s code rule
  never reached it.

## Table of Contents

- Without `IntersectionObserver`, the TOC skips a heading with no layout box, such as
  one inside a closed `<details>`, so it never becomes the active section while the
  reader is in an earlier one.
