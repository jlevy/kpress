Source Code Pro is the interim mono because it is Source Sans 3's companion. Decide the final face against stated criteria: x-height and stroke weight beside PT Serif and Source Sans 3 at the mono size token, distinguishable 0/O and 1/l/I, OFL or equivalent licence, latin subset size, a static regular and bold, availability from a pinned fontsource release. Candidates: Source Code Pro, IBM Plex Mono, JetBrains Mono, Fira Mono, Commit Mono. Render the same code sample in each beside the prose on screen and in the PDF, and pick by measurement and a look, then swap the vendored files if the choice changes.
