Follow-up to KPress PR 59 and Squares think-ws53. A missing katex-text-face.css leaves composite warmup empty but still displays stock glyphs with PT Serif metric tables: fraction height 1.389em versus stock 1.3214em. Fall back coherently when the selected composite is absent, preserve required-face error handling and failed unused weights, and preserve intentional whole-document experimental metrics.

## Notes

# Composite Fallback Review

Verdict: pass for the uncommitted change. No remaining actionable findings.

The runtime chooses matching stock metrics and CSS when the selected composite family
has no registered font declarations. The choice is per profile, so a missing serif
family does not disable a healthy sans family. Declaration presence is independent of
font load status; the existing rendered-glyph check still rejects required-face errors.

The declaration check is smaller than interpreting an empty warmup request as a fatal
error, which would discard healthy formulas when an unused style is missing. It reuses
the existing stock metrics and CSS marker. No new dependency, asset, or font request is
introduced. Whole-document opt-outs keep the host's intentionally patched KaTeX tables.

Confirmed benign: a failed unused bold weight keeps a regular custom formula; a failed
required regular face retains semantic MathML; nested stock overrides continue to draw
stock glyphs. The parent agent also independently reviewed the diff without findings.

Validation: all 724 Python tests passed on standard CPython 3.14.6 with required browser
mode enabled; all 228 JavaScript tests passed. Lint, formatting, types, generated fonts
and metrics, supply-chain policy, both vulnerability audits, and distribution checks
passed. The three missing-declaration browser cases and stock-metric unit case failed
before the runtime change. Golden regeneration produced no diff.

The public API and design documentation now distinguish absent declarations from
failed required faces and document the error when selected metric tables are missing.
